# 蓝色星原简体汉化 / 尔安 问题反馈QQ群：1055713417（随时不在线，目前没人）

《蓝色星原：旅谣》台服、日服游戏及启动器的简体中文汉化工具，支持汉化、还原和文件状态检查。

> **如出现无法登录，请还原文件。本项目未进行反作弊测试，不保证后续版本兼容。**

## 下载

前往 [Releases](https://github.com/xiayuan0817/Azur-Promilia-Chinese-Translation-Script/releases) 下载完整汉化包：

**`AzurPromilia-Localization-Full-v3.zip`**

完整包包含运行脚本和替换资源，无需另行准备国服包体。

**仓库源码不包含游戏替换资源，直接下载仓库 ZIP 无法完成汉化。**

## 操作方法

1. 完整解压汉化包，保留原有目录结构。
2. 完全退出游戏和启动器，包括托盘中的后台程序。
3. 双击 **`双击运行.bat`**。
4. 输入编号并回车执行。

| 选项 | 功能 |
| --- | --- |
| 1 | 全部汉化 |
| 2 | 全部还原 |
| 3 | 选择项目汉化 |
| 4 | 选择项目还原 |
| 5 | 查看文件及备份状态 |
| 6 | 完整校验（含分段与整包 CRC32） |
| 7 | 手动添加/修改安装目录（支持保存至 `tools/安装路径.json`） |
| Q | 退出 |

选择部分项目时，多个编号用逗号分隔，例如 `1,3`；回车选全部，`0` 或 `q` 取消。

- 自动查找常见位置、注册表、运行进程及桌面/开始菜单快捷方式中的安装目录。
- 未找到时，可将安装文件夹拖到 **`双击运行.bat`** 图标上，或按窗口提示输入路径。
- 选项 `7` 可添加或修改安装目录；输入 `Y` 保存，下次自动读取，`N` 仅本次使用。
- 也可在 `tools/安装路径.json` 中填写绝对路径。

## 支持版本

| 项目 | 对应版本 |
| --- | --- |
| 台服游戏 | 资源版本 `3221745` |
| 日服游戏 | 资源版本 `3219598`，内置资源版本 `3075915` |
| 台服启动器 | `1.0.1.4` |
| 日服启动器 | `1.8.1` |

若游戏仅进行未改动汉化段的小幅热更（如台服 `3221745 -> 3221746`），工具会自动校验新清单 MD5 并按段适配；若热更修改了目标汉化段或提示版本不匹配，请停止操作，等待对应版本的汉化包。

## 汉化范围

- 台服游戏文本及相关字体资源。
- 日服游戏文本、内置启动文案及相关字体资源。
- 台服、日服启动器界面。

主要采用国服官方简体文案。服务器动态下发的内容及图片内文字可能仍显示原文。

## 资源校验

游戏资源汉化采用等长替换及 CRC 配平方案，目标是保留原版资源大小、分段 CRC 和整包 CRC。


## 备份与还原

汉化前会备份原版文件，请勿手动删除：

| 项目 | 备份位置 |
| --- | --- |
| 台服游戏 | 游戏目录下 `.zhcn-crc-readonly-3221745-backup` |
| 日服游戏 | 游戏目录下 `.zhcn-jp-crc-readonly-3219598-backup` |
| 启动器 | `resources/app.asar.before-zhcn-20261124.bak` |

更新游戏或启动器前，建议先还原文件。

报错时请查看窗口提示；本次操作日志位于 `tools/logs`。

## 源码目录

```text
├─ 双击运行.bat        # 运行入口（支持拖拽安装目录）
├─ tools/              # 汉化菜单、路径查找、公共校验核心、部署与还原
├─ CRC工具/
│  ├─ crc/             # 台服资源处理与校验工具
│  └─ jp_crc/          # 日服资源处理与校验工具
├─ tests/              # 隔离自测套件（不触碰真实游戏目录）
├─ build_release.py    # 清单校验/刷新与发布包构建脚本
└─ README.md           # 项目说明
```

CRC 工具目录包含资源分析、构建、校验脚本及报告；部分脚本依赖原始资源、外部库和本地路径，不能直接作为独立程序运行。

### 开发者校验与自测

```bash
python build_release.py --verify-repo
python tests/run_tests.py
```

修改 `tools/` 下脚本后，可运行 `python build_release.py --refresh-manifest` 更新 `tools/package-files.json` 中的非载荷文件校验值（不改动 `payload/` 哈希）。
