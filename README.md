《蓝色星原：旅谣》台服、日服游戏及启动器的简体中文汉化工具，支持汉化、反虚化、还原和文件校验。

## 下载

前往 [Releases](https://github.com/xiayuan0817/Azur-Promilia-Chinese-Translation-Script/releases) 下载完整汉化包：

**`AzurPromilia-Localization-Full-v6.zip`**

完整包包含运行脚本和替换资源，无需另行准备国服包体。

**仓库源码不包含游戏替换资源，直接下载仓库 ZIP 无法完成汉化。**

## 操作方法

1. 完整解压汉化包，保留原有目录结构。
2. 需要修改文件的项目，先退出对应游戏或启动器，包括托盘程序。
3. 双击 **`双击运行.bat`**。
4. 输入编号并回车执行。

| 选项 | 功能 |
| --- | --- |
| 1 | 全部汉化 |
| 2 | 全部还原 |
| 3 | 选择项目汉化 |
| 4 | 选择项目还原 |
| 5 | 查看文件及备份状态 |
| 6 | 完整校验（含分段与整包 CRC32） |
| 7 | 手动添加/修改安装目录（支持保存至 `tools/安装路径.json`） |
| 8 | 日服反虚化 |
| 9 | 还原日服反虚化 |
| 10 | 台服反虚化 |
| 11 | 还原台服反虚化 |
| U | 检查并更新汉化包 |
| Q | 退出 |

台服、日服反虚化均从同一个 `双击运行.bat` 菜单操作，不随全部汉化或全部还原执行；选项 `5`、`6` 包含其文件、备份状态及 CRC32 检查。反虚化资源对应日服 `1.0.2`、台服资源版本 `3221746`，仅接受匹配的原版或本版文件。

选择部分项目时，多个编号用逗号分隔，例如 `1,3`；回车选全部，`0` 或 `q` 取消。

各项目仅检查自身进程；已汉化或已还原的项目直接跳过。某项正在运行时，提示原因并继续处理其他项目。

- 自动查找常见位置、注册表、运行进程及桌面/开始菜单快捷方式中的安装目录。
- 未找到时，可将安装文件夹拖到 **`双击运行.bat`** 图标上，或按窗口提示输入路径。
- 选项 `7` 可添加或修改安装目录；输入 `Y` 保存，下次自动读取，`N` 仅本次使用。
- 也可在 `tools/安装路径.json` 中填写绝对路径。

## 更新汉化包

双击 **`双击运行.bat`**，红色提示下方会先检查上游版本，按回车可跳过检查。只有上游版本高于本地时才提示更新，随后加载功能菜单；版本相同、断网或检查失败均不影响使用。输入 **`U`** 并回车即可更新汉化包。

也可在汉化包目录打开 CMD，执行：

```bat
双击运行.bat check-update
双击运行.bat update
```

`check-update` 仅检查，`update` 下载本仓库最新正式版的完整包，无需安装 Git。按版本号判断更新，同版本不重复更新，也不会降级。

更新前关闭其他汉化脚本窗口。脚本自动下载、解压并校验完整包后替换文件；替换失败时恢复原文件。保留 `tools/安装路径.json`、日志及游戏目录中的原版备份。更新成功后自动重新加载菜单，按需执行汉化。

## 资源基线与启动器版本

| 项目 | 对应版本 |
| --- | --- |
| 台服游戏 | 资源版本 `3221745` |
| 日服游戏 | 资源版本 `3219598`，内置资源版本 `3075915` |
| 台服启动器 | `1.0.1.4` |
| 日服启动器 | `1.8.1` |

资源版本变化时，自动检查清单与目标资源段是否兼容；不兼容时停止操作。

## 功能范围

- 台服游戏文本及相关字体资源。
- 日服游戏文本、内置启动文案及相关字体资源。
- 台服、日服启动器界面。
- 台服、日服反虚化，支持安装、还原、状态检查及 CRC32 校验。

主要采用国服官方简体文案。服务器动态下发的内容及图片内文字可能仍显示原文。

## 资源校验

游戏资源汉化采用等长替换及 CRC 配平方案，目标是保留原版资源大小、分段 CRC 和整包 CRC。

保留资源基线检查；兼容的小幅热更可自动适配。操作前校验资源、只读清单及备份；目标段变化、匹配不唯一或校验失败时停止操作。


## 备份与还原

汉化或反虚化前会备份原版文件，请勿手动删除：

| 项目 | 备份位置 |
| --- | --- |
| 台服游戏 | 游戏目录下 `.zhcn-crc-readonly-3221745-backup` |
| 日服游戏 | 游戏目录下 `.zhcn-jp-crc-readonly-3219598-backup` |
| 日服反虚化 | 游戏目录下 `.jp-deblur-1.0.2-backup` |
| 台服反虚化 | 游戏目录下 `.tw-deblur-3221746-backup` |
| 启动器 | `resources/app.asar.before-zhcn-20261124.bak` |

更新游戏或启动器前，建议先还原文件。

报错时请查看窗口提示；本次操作日志位于 `tools/logs`。

## 源码目录

```text
├─ 双击运行.bat        # 运行入口（支持拖拽安装目录）
├─ tools/              # 统一菜单、路径查找、汉化与反虚化部署、校验及还原
├─ CRC工具/
│  ├─ crc/             # 台服资源处理与校验工具
│  ├─ jp_crc/          # 日服资源处理与校验工具
│  └─ resource_decode/ # 资源解码、语言表与字符串池工具
├─ tests/              # 隔离自测套件（不触碰真实游戏目录）
├─ build_release.py    # 清单校验/刷新与发布包构建脚本
└─ README.md           # 项目说明
```

CRC 工具目录包含资源分析、构建、校验脚本及报告；部分脚本依赖原始资源、外部库和本地路径，不能直接作为独立程序运行。

### 开发者校验与自测

```bash
python build_release.py --verify-repo
python tests/run_tests.py
```

修改 `tools/` 下脚本后，可运行 `python build_release.py --refresh-manifest` 更新 `tools/package-files.json` 中的非载荷文件校验值（不改动 `payload/` 哈希）。

构建时同时生成 `dist/update.json`。上传完整包后，将此文件同步到仓库根目录，供启动时检查版本。
