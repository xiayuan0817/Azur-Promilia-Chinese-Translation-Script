# 运行工具

| 文件 | 用途 |
|---|---|
| `Manage-Localization.ps1` | 操作菜单与任务调度 |
| `Locate-Installations.ps1` | 查找、设置及保存安装目录 |
| `Localization-Common.ps1` | 公共校验、备份、还原及进程检查 |
| `Region-Identity.ps1` | 读取游戏与启动器区服 |
| `Apply-CRCZH.ps1` | 台服游戏备份、替换、校验与还原 |
| `Apply-JPCRCZH.ps1` | 日服游戏备份、替换、校验与还原 |
| `Apply-JPDeblur.ps1` | 日服反虚化安装、还原及校验 |
| `Apply-TWDeblur.ps1` | 台服反虚化安装、还原及校验 |
| `Apply-Launchers.ps1` | 两服启动器备份、汉化与还原 |
| `tw-deployment.json` | 台服游戏文件清单 |
| `jp-deployment.json` | 日服游戏文件清单 |
| `jp-deblur-deployment.json` | 日服反虚化部署与校验配置 |
| `tw-deblur-deployment.json` | 台服反虚化部署与校验配置 |
| `launcher-deployment.json` | 两服启动器文件清单 |
| `package-files.json` | 安装包文件校验清单 |
| `安装路径.json` | 手动指定安装位置 |

使用时请下载 Releases 中的完整包，包含运行所需的全部 payload 替换资源。
